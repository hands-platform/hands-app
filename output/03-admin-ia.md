# HANDS Admin IA

## 운영 목표
- 운영자가 고객, 파트너, 예약, 결제, 정산, 세금, 알림, 채팅 기록을 한 화면 구조 안에서 빠르게 확인하고 조치할 수 있게 한다.
- 사람을 점수화하거나 리스크 판단하지 않는다. 대신 사실 기반 활동 내역, 상태, 시간, 금액, 조치 기록을 보여준다.
