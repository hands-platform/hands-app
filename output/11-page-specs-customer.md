# Customer Page Specs

## Home

- Address confirmation card
- Nearby partner preview
- Current booking shortcut
- Refresh partners action

## Address Selection

- MapTiler/MapLibre map
- Geoapify search field with debounce and simple cache
- Current-location button
- Center fixed pin
- Search results list
- Use this location button
- Permission denied state with manual search fallback

## Partner List

- Partner thumbnail or initials placeholder
- Partner display name
- Distance from selected address
- Availability state
- Service summary
- Factual feedback count
- Reserve/open detail action

## Partner Detail

- Public photos
- Display name
- Distance and availability
- About/profile text
- Services and duration options
- Feedback/review records
- Booking entry action

## Booking Information

- Customer contact/address snapshot
- Selected partner
- Selected service and duration
- Payment method
- Price and policy snapshot
- Book now action

## Matching Wait

- First-pick partner status
- Marketplace candidate list
- Countdown
- Refresh status
- Customer final partner selection

## Chat

- Active matched booking messages
- Send message
- Location preview if available
- No tip or gratuity controls
