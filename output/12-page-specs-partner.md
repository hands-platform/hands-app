# Partner Page Specs

## Requests

- Online/offline control
- Last location update status
- Direct first-pick request cards
- Marketplace request cards
- Join/accept/reject actions
- Wallet settlement gate message when blocked

## Request Card

- Service name and duration
- Booking ID
- Customer display/contact where policy allows
- Address summary
- Distance from booking address
- Role: first-pick or marketplace candidate
- Decision state
- Next action

## Chat

- Active matched booking room
- Refresh chat
- Send message
- Share current location button
- Route preview placeholder only; no directions API

## Earnings

- Completed service list
- Wallet ledger
- Platform fee debt
- Payout batch state
- Tax/withholding snapshot

## Profile and Onboarding

- Basic profile
- KYC state
- Bank account readiness
- Tax profile readiness after first revenue
- Agreement versions
- Documents and re-upload state
