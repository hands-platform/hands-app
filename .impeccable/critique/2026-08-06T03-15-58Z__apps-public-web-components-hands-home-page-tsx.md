# HANDS 홈페이지 브랜드·UX 감사

## 감사 범위

- 대상: `apps/public_web/components/hands-home-page.tsx`
- 실행 화면: `http://localhost:3200/ko`
- 고객 목표: 5초 안에 서비스가 무엇인지 이해하고, 안전하다고 느끼며, 가까운 테라피스트를 찾는 행동으로 이동하기
- 접근성 목표: WCAG 2.2 AA에 가까운 대비·키보드·터치·반응형 기본기

## 한 줄 결론

시각적 첫인상은 프리미엄이지만, 마사지보다 범용 피트니스에 가까운 이미지와 공개 테스트 데이터가 브랜드 신뢰를 무너뜨립니다. 가장 큰 기회는 새 디자인을 만드는 것이 아니라, 현재의 좋은 아트 디렉션을 유지한 채 **“검증된 마사지 테라피스트가 원하는 시간과 장소로 찾아온다”**는 약속과 실제 증거를 앞으로 당기는 것입니다.

## 단계별 화면 감사

### 1. 데스크톱 첫 화면 — 양호, 전환 초점 분산

![데스크톱 첫 화면](C:/dev/massage-on-demand-vn/output/brand-homepage-audit-2026-08-06/01-desktop-hero.png)

- 강점: 실제 서비스 현장을 연상시키는 테라피스트 이미지, 강한 타이포그래피, 차분한 톤.
- 위험: 상단 내비게이션, 앱 다운로드, 시작하기, 둘러보기, 영상까지 다섯 행동이 경쟁합니다.
- 문구 위험: “가장 편안한 웰니스 공간”은 분위기는 좋지만 고객이 무엇을 예약하는지 한 번 더 해석해야 합니다.
- 기본 1280px 폭에서는 영상 카드 문구가 여러 짧은 줄로 찢어져 히어로와 경쟁합니다.

### 2. 가치 설명 — 구조는 좋지만 대비와 반복이 약점

![가치 설명 구간](C:/dev/massage-on-demand-vn/output/brand-homepage-audit-2026-08-06/03-desktop-service-story.png)

- 강점: 가까움·투명함·연결이라는 3개 축은 서비스 모델을 쉽게 설명합니다.
- 위험: 큰 회색 제목 대비가 `1.50:1`로 측정되어 텍스트 접근성이 매우 낮습니다.
- 위험: 이후 기능 레일·HANDS METHOD·이용 단계·FAQ가 같은 내용을 반복해 페이지가 길어집니다.

### 3. 이용 방법 — 명확한 흐름, 잘못된 이미지 언어

![이용 단계](C:/dev/massage-on-demand-vn/output/brand-homepage-audit-2026-08-06/09-desktop-how-step.png)

- 강점: 주소 선택 → 테라피스트 선택 → 예약 후 기다림이라는 순서가 명확합니다.
- 위험: 달리기·요가 이미지는 마사지 예약보다 운동·코칭 서비스를 연상시킵니다.
- 접근성: 단계 점 버튼은 `21–35×30px`로 일반적인 `44×44px` 터치 목표보다 작습니다.

### 4. 후기와 실제 공급 — 신뢰 취약

![고객 후기](C:/dev/massage-on-demand-vn/output/brand-homepage-audit-2026-08-06/10-desktop-testimonials.png)

![모바일 테라피스트 목록](C:/dev/massage-on-demand-vn/output/brand-homepage-audit-2026-08-06/22-mobile-faq.png)

- 후기 이름과 사진이 범용 스톡 콘텐츠처럼 보이고 대부분 `HANDS 고객 · 2026`으로 동일합니다.
- 실제 목록은 `Linh Wellness` 1개와 `Smoke Partner` 4개, 빈 프로필 이미지로 표시됩니다.
- 집으로 방문하는 서비스는 일반 커머스보다 신뢰 문턱이 높습니다. 이 상태에서는 어떤 고급 디자인도 의심을 이기기 어렵습니다.

### 5. 모바일 탐색 — 사용 가능하지만 너무 김

![모바일 첫 화면](C:/dev/massage-on-demand-vn/output/brand-homepage-audit-2026-08-06/14-mobile-hero.png)

![모바일 기능 카드](C:/dev/massage-on-demand-vn/output/brand-homepage-audit-2026-08-06/17-mobile-service-card.png)

- 모바일 문서 높이는 `11,094px`, 약 `13.1`개 화면입니다.
- 기능 카드 3개가 각각 `982px`, 합계 `3,017px`를 사용하며 복사 영역에 `min-height: 740px`가 적용돼 큰 빈 공간이 생깁니다.
- 실제 테라피스트 목록은 `9,289px` 이후에 등장합니다. 고객은 증거를 보기 전에 거의 전체 페이지를 지나야 합니다.
- 후기 레일은 `375px` 화면 안에서 `2,026px`로 가로 넘침이 있지만 이전/다음 버튼이나 명확한 스와이프 안내가 없습니다.

### 6. 마지막 CTA와 법적 정보 — 시각은 양호, 브랜드 신뢰는 위험

![모바일 푸터](C:/dev/massage-on-demand-vn/output/brand-homepage-audit-2026-08-06/24-mobile-legal-footer.png)

- 마지막 CTA는 크고 선명하지만 다시 요가 이미지를 사용해 마사지 서비스의 정체성이 희석됩니다.
- `대표: 정보 등록 예정`, `사업자 주소: 정보 등록 예정`은 공개 페이지에서 출시 전 상태처럼 보입니다.
- 최종 인상이 신뢰가 아니라 미완성으로 끝나므로 Peak-End Rule 관점에서 전환에 큰 손해입니다.

## Design Specificity Verdict

### 디자인 디렉터 판단

현재 HANDS는 시각적으로는 저자성이 있습니다. 풀블리드 이미지, 초대형 한글 타이포, 종이 같은 배경, 코랄·블루·라일락 패널은 기억에 남습니다. 그러나 히어로 이후의 이미지와 문구는 웰니스 업계 공용 언어에 가깝습니다. 운동 사진을 마사지 현장 사진으로 교체하고, 추상 명사를 운영 증거로 바꾸면 같은 레이아웃을 유지해도 브랜드 고유성이 크게 올라갑니다.

### 자동 검사

`apps/public_web/components` 전체에서 자동 디자인 탐지 결과는 0건이었습니다. 즉, 금지된 구현 패턴은 보이지 않았습니다. 다만 자동 검사는 테스트 데이터, 문구의 진실성, 브랜드 적합성, 실제 대비를 판단하지 못합니다. 브라우저 측정에서 자동 검사 밖의 문제인 `1.50:1` 대비, 작은 단계 버튼, 모바일 11,094px 길이, 3,017px 기능 레일이 확인됐습니다.

### 시각 오버레이

브라우저가 읽기 전용 페이지 평가만 제공해 신뢰할 수 있는 오버레이 주입은 불가능했습니다. 별도 오버레이 서버나 스크립트는 실행하지 않았고, 저장·검수한 화면과 DOM·계산 스타일·레이아웃 수치를 대체 증거로 사용했습니다.

## 잘 작동하는 부분

1. **프리미엄 첫인상:** 기존 히어로와 중립 팔레트는 유지 가치가 큽니다.
2. **이해 가능한 기본 모델:** 가까운 사람 찾기, 비교, 예약 후 확인이라는 구조는 단순합니다.
3. **접근성 기반 일부:** 네이티브 `details/summary`, 레이블이 있는 단계 버튼, 주요 스크롤 효과의 reduced-motion 분기가 있습니다.

## 우선순위 이슈

### [P1] 테스트·미등록 정보가 신뢰를 파괴함

- 왜 중요한가: 방문형 마사지 서비스에서 신뢰는 전환의 전제입니다.
- 수정: `Smoke Partner`, 빈 이미지, 미등록 사업자 정보, 검증되지 않은 후기를 공개 화면에서 제거하고 실제 데이터만 노출합니다. 실제 데이터가 부족하면 테라피스트 목록·후기를 숨기고 모집/오픈 준비 메시지로 솔직하게 대체합니다.
- 추천 명령: `$impeccable harden`

### [P1] 마사지가 아닌 범용 웰니스로 보임

- 왜 중요한가: 고객이 “무슨 서비스인지” 이해하는 데 추가 해석이 필요합니다.
- 수정: 운동·요가 이미지를 방문 준비, 깨끗한 타월·오일, 테라피스트 도착, 실제 프로필, 서비스 진행 전 안내 같은 마사지 고유 장면으로 교체합니다.
- 추천 명령: `$impeccable bolder`

### [P1] 첫 CTA의 의미와 목적지가 모호함

- 왜 중요한가: “시작하기”는 페이지 하단으로만 이동하고 “앱 다운로드”도 실제 다운로드보다 파트너 경로를 가리킵니다.
- 수정: 첫 CTA는 `/ko/partners`의 실제 탐색으로 연결하고 “내 주변 테라피스트 보기”로 명명합니다. 보조 CTA는 “3분 예약 과정 보기” 하나만 둡니다.
- 추천 명령: `$impeccable clarify`

### [P2] 신뢰 설명이 너무 늦고 추상적임

- 왜 중요한가: 고객은 집에 사람을 부르기 전에 검증 방식, 가격, 취소·지원 기준을 먼저 확인합니다.
- 수정: 히어로 바로 아래에 실제로 증명 가능한 3개 신뢰 근거를 배치하고, 안전 섹션에는 검증 항목과 지원 흐름을 구체적으로 적습니다.
- 추천 명령: `$impeccable distill`

### [P2] 모바일이 반복적이고 과도하게 김

- 왜 중요한가: 실제 테라피스트가 11개 화면 아래에 있어 첫 방문자가 증거에 도달하기 어렵습니다.
- 수정: 3개 기능 패널의 고정 최소 높이를 제거하고 이미지 4:3 + 문구 + CTA의 콘텐츠 높이 카드로 압축합니다. 실제 테라피스트 3명을 2–3번째 화면에 배치합니다.
- 추천 명령: `$impeccable adapt`

## 추천 브랜드 포지셔닝

**핵심 약속:** `오늘 필요한 마사지를, 원하는 곳에서.`

**설명 문장:** `위치와 시간을 선택하면 가까운 검증 테라피스트를 비교하고 바로 예약할 수 있어요. 예약 후에는 채팅과 실시간 상태로 도착부터 완료까지 확인하세요.`

브랜드 언어는 다음 네 가지 원칙을 권합니다.

1. **웰니스보다 마사지 먼저:** 카테고리를 먼저 말한 뒤 감성 가치를 더합니다.
2. **추상어보다 행동:** 연결·순간·공간보다 찾기·비교·예약·도착·지원.
3. **안심은 근거와 함께:** “검증된”이라고만 쓰지 말고 무엇을 확인하는지 보여줍니다.
4. **사람을 존중하는 따뜻함:** 테라피스트를 상품 목록이 아니라 전문 서비스 제공자로 표현합니다.

## 추천 페이지 구조

1. **히어로:** 한 문장 약속 + 주 CTA 1개 + 보조 CTA 1개.
2. **신뢰 바:** 실제 검증·가격·지원 근거 3개.
3. **가까운 실제 테라피스트:** 사진, 지역, 서비스, 시작 가격, 평점, 검증 상태.
4. **예약 방법:** 주소 → 비교 → 예약·상태 확인.
5. **안전과 지원:** 검증 절차, 기록, 신고·분쟁 지원.
6. **실제 예약 후기:** 검증 예약 배지와 구체적 서비스·지역 맥락.
7. **FAQ + 최종 CTA.**

현재의 가치 섹션·기능 레일·HANDS METHOD 중 하나만 남겨 중복을 줄입니다. 가장 권하는 방식은 기능 레일을 삭제하고 실제 테라피스트 카드와 안전 근거로 대체하는 것입니다.

## 이미지 아트 디렉션

### 유지

- 히어로의 테라피스트 준비 장면
- 따뜻한 자연광, 중립 배경, 차분한 녹색과 오프화이트
- 사람 중심의 다큐멘터리 톤

### 교체

- 달리기·요가·헬스장 이미지를 모두 제거
- 다음 5개 장면으로 일관된 스토리 구성:
  1. 고객 집에 도착한 테라피스트
  2. 깨끗한 타월·오일·도구 준비
  3. 실제 프로필·서비스·가격을 비교하는 화면
  4. 서비스 전 상담과 안전 확인
  5. 서비스 후 편안한 고객과 후기

스톡 느낌을 줄이려면 같은 1–2명의 테라피스트와 동일 공간을 여러 장면에서 이어 사용합니다. 피부 노출이나 운동복 중심 사진보다 전문성·위생·안심을 보여주는 손과 도구, 눈맞춤, 준비 과정을 우선합니다.

## 접근성 개선

- 회색 대형 제목은 최소 `4.5:1` 대비가 나오는 색으로 변경합니다. 장식용이라도 실제 텍스트이므로 예외로 두지 않습니다.
- 단계 점과 캐러셀 제어는 최소 `44×44px` 클릭 영역을 제공합니다.
- 후기 레일에 이전/다음 버튼, 현재 위치, “좌우로 넘기기” 단서를 추가합니다.
- 모든 CTA에 명확한 `:focus-visible` 스타일을 통일합니다.
- 200% 확대, 키보드 순서, 스크린리더 상태 알림은 별도 상호작용 테스트로 검증합니다.

## 증거 한계

- 화면과 소스만으로 후기·검증 배지의 진위, 운영 검증 절차, 고객지원 SLA를 확인할 수 없습니다.
